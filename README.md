# html-inject-scan (C++)

Консольный инструмент на C++ для автоматизированного поиска отражённых HTML-инъекций
в веб-приложениях. Принимает список URL, обнаруживает параметры (из query string URL,
HTML-атрибутов `name=` и пользовательского словаря), подставляет payload и проверяет,
отражается ли заданный маркер в ответе сервера. Поддерживает авторизованные сессии через
пользовательские HTTP-заголовки и cookie.

> Переписанная на C++ версия Python-инструмента `html-inject-scan`. Подробное руководство
> пользователя будет дополнено по мере реализации модулей.

## Сборка

```bash
cmake -B build
cmake --build build
```

## Запуск тестов

```bash
ctest --test-dir build
```

## Запуск

```bash
./build/html-inject-scan
```

## Зависимости

- [cpr](https://github.com/libcpr/cpr) — HTTP-клиент (подтягивается через CMake `FetchContent`).
- [doctest](https://github.com/doctest/doctest) — модульные тесты (через `FetchContent`).

Внешних установок не требуется: всё собирается CMake.
